# Security incidents and service outages

## Compromised accounts
Treat suspected hacked, stolen or compromised accounts and phishing reports as urgent security
incidents. Escalate to the security response team. Recommend changing a password through the
official account settings and revoking exposed API keys through the secure console. Never ask
the customer to provide a current password or token. Do not claim that containment is complete.

## Outages
For a production outage affecting multiple users, collect the affected service, start time,
region and request IDs. Check the official status page and escalate to technical support.
Avoid promising a recovery time without an approved incident update.
