# Account access and password recovery

## Password reset
Choose Forgot password on the sign-in page and enter the registered email address. A password
reset link expires after 30 minutes. Check the spam folder and request a fresh link if it has
expired. Never share passwords or recovery codes with support agents.

## Two-factor authentication
Use a saved recovery code if the authenticator is unavailable. If recovery codes are lost,
request account recovery through the verified support channel. Support must verify ownership
before changing account access. Agents cannot disable two-factor authentication on request alone.
